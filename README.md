# Magic Number Checker in Java

## Description
This Java program checks whether a given number is a magic number. It repeatedly calculates the sum of the digits until a single-digit number is obtained. If the final result is 1, the number is considered a magic number.

## Features
- Checks whether a number is a magic number.
- Uses nested while loops.
- Demonstrates digit sum calculation.
- Beginner-friendly Java program.

## Technologies Used
- Java
- While Loop
- Conditional Statements
- Arithmetic Operations

## Program Logic
1. Initialize a number.
2. Calculate the sum of its digits.
3. Repeat the process until a single-digit number is obtained.
4. If the final digit is 1, print "Magic Number"; otherwise, print "Not a Magic Number".

## Sample Output

### Input

172


### Output

172    magic number
